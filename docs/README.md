# Documentation structure

This directory contains the canonical documentation for the system.
These documents define the product, architecture, contracts, governance model, and implementation sequencing.

## Sections

- `00-foundation` — foundational system definition and boundaries
- `01-architecture` — architectural views and subsystem structure
- `02-contracts` — MCP, API, tool, and integration contracts
- `03-governance` — policy, audit, retention, permissions, evaluation
- `04-implementation` — implementation decomposition and execution order

## Rule

Documents in this area are the source of truth for the system design.
They should remain distinct from future code directories.
